⚠️ IMPORTANT : le champ de saisie de la sandbox est une ligne UNIQUE
(QLineEdit) — il ne supporte pas le retour à la ligne. Toutes les
réponses ci-dessous tiennent donc sur une seule ligne. Exception : le
widget CODE a besoin d'un vrai bloc multi-lignes, impossible à coller
proprement ici — utilisez plutôt verifier_selection.py pour ce cas
(un exemple Python y est déjà prêt).

Chaque réponse est précédée d'une ligne « › ... » qui indique ce qui
est attendu — NE COLLEZ PAS cette ligne, seulement la phrase qui suit.
